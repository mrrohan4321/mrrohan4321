### 🚀 Projects

**[AI Travel Intelligence](https://github.com/mrrohan4321/ai-travel-intelligence)**
An AI trip planner for Indian domestic travel. Give it a destination, budget, dates, group size and travel style, and it researches the place live (SerpApi), checks real weather (Open-Meteo) and road distances (Nominatim + OSRM), prices the whole trip line by line with a deterministic cost engine, and writes a day-by-day itinerary plus a PDF to carry on the road. Has an instant "What if?" mode to re-plan on a different budget, headcount or transport. Built entirely on free tiers. [🎥 Demo](https://youtu.be/anAh1D-6G3k)

**[ECG Signal Classification](https://github.com/mrrohan4321/ECG-Project-Deeplearning)**
Group 7 deep learning project — classifies ECG heartbeats as Normal or Abnormal with a 1D-CNN and a CNN-LSTM on the MIT-BIH Arrhythmia Database, and benchmarks GPU vs CPU speed for training and inference. Comes with a live Streamlit demo. Educational project, not a clinical diagnosis. [🌐 Live app](https://ecg-project-deeplearning-6383kyappwquwvbrmgodag6.streamlit.app/) · [🎥 Demo](https://youtu.be/or2yRLIMrqw)

**[AB Electricals Website](https://ab-electrical.netlify.app/)**
Full storefront site for our family showroom — built from scratch in plain HTML/CSS/JS, deployed via Git/Netlify, with a custom warm amber theme, cursor-reactive spotlight, animated UI touches and embedded Google Reviews. Showcases the brands we carry (Havells, Bajaj, Maru, Diamond Lights). [📦 Repo](https://github.com/mrrohan4321/ab-electricals-website)

**[Safar](https://safar-adfree.netlify.app/)**
An ad-free, installable music player — streams through YouTube's own embedded player with no extra ads or tracking, built around the idea that every road has a song of its own (*প্রতিটা রাস্তার নিজের একটা গান থাকে*). Installable PWA with queue view, playlist switcher, keyboard shortcuts and lock-screen media controls, all in a single `index.html`. [📦 Repo](https://github.com/mrrohan4321/safar-site)

**[Keystroke Gunshot](https://github.com/mrrohan4321/keystroke-gunshot)**
A system-wide desktop app in Python (pynput + pygame) that plays a gunshot sound on every keystroke in any app. The sound is synthesised in code, so no audio file is needed, and it never records or sends what you type.
